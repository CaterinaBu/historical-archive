## Правила изображений

- По одной утверждённой аватарке на персонажа.
- Холст 1024 × 1024 px, формат PNG RGBA, настоящая прозрачность вне круга.
- Расположение круга: ориентир — центр (512, 541), радиус около 431 px. Все 11 изображений выровнены масштабированием исходных композиций; оттенок и толщина живописной рамки могут немного различаться.
- Лицо и ключевая эмоция должны читаться при отображении около 120 CSS px.
- Голова и причёска могут выступать за рамку, плечи и туловище остаются внутри.
- Избегать типичных нейросетевых наклонов головы, поднятого подбородка, одинаковых острых скул и неправдоподобно развитых мышц.
- Имя и должность выводятся текстом интерфейса, а не встраиваются в изображение.
- При следующих генерациях применять технический стандарт сразу; сохранять утверждённую внешность.
- У Алисы утверждена высокая объёмная причёска вместо каре. У Тимофея — прямой ракурс и мягкие скулы.

## Подключение в игру

Если каталог будет перемещён в `public/assets/characters/avatars/`, обращайтесь к аватаркам по URL `/assets/characters/avatars/elena-mironova.png`. Иначе импортируйте через сборщик проекта.

```css
.character-avatar {
  display: block;
  width: 120px;
  height: 120px;
  object-fit: contain;
  flex-shrink: 0;
}
```

**Не применять** `border-radius: 50%` или `overflow: hidden` — иначе обрежутся выступающие из круга детали.

### Слои и версия изображений

**Важно:** волосы, голова, поднятые руки и предметы должны перекрывать круглую рамку там, где выступают за неё. Не дорисовывать кольцо последним слоем поверх готового персонажа. Исправленный комплект подготовлен из оригинальных рисунков без дополнительной рамки поверх волос. Старые PNG, загруженные ранее, нужно заменить исправленным комплектом; README сам по себе не изменяет бинарные файлы.
