# Датасет игры «Исторический архив»

Документация к игровой базе исторической викторины VK Mini Apps.

## Версия от 23 ноября 2026 года

- 390 исторических личностей в 10 категориях
- 2 681 активный исторический факт
- 2 254 автоматически сформированных вопроса с четырьмя вариантами ответа

**Предполагаемый путь файла:** `data/historical_archive_data.xlsx`. Сам Excel пока не загружен в GitHub; файл был подготовлен в чате.

## Листы Excel

| Лист | Содержимое |
| --- | --- |
| Персоны | Идентификаторы, имена и категории |
| Факты | Данные о личностях, источники, ссылки на открываемые факты |
| Вопросы | Четыре варианта, правильный ответ и связь с фактом |
| Широкий формат | Одна строка на личность |
| Проверка | Технические проверки целостности |
| Инструкция | Описание структуры |

## Принципы использования

Игрок получает сведения о личности только после правильного ответа. Спорные значения исключены или заменены; специальную логику приблизительных дат добавлять не нужно. Не все факты используются для автоматически составленных вопросов: свободные описания могут оставаться в коллекции.

## Статус проверки

Проведены сверка исторических данных и технические проверки заполнения. У каждой из 390 личностей не менее трёх фактов, проверена уникальность пары «личность — поле». Для автоматически подготовленных вопросов проверена структура: четыре различных варианта и один отмеченный правильный ответ.

Перед запуском требуется интеграционное тестирование с кодом игры и редакторская проверка формулировок вопросов. Первоначальный широкий XLSX не был доступен при сборке: широкий лист восстановлен по реестру.

Этот файл описывает **только датасет**, а не проект целиком.
