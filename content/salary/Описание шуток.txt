ШУТКИ БУХГАЛТЕРИИ — ИСТОРИЧЕСКИЙ АРХИВ
Версия: 27 ноября 2026 года.

Файл: salary-jokes.json
Назначение: короткие реплики бухгалтерии в уведомлении о начислении ежедневной зарплаты.
Состав: 100 утверждённых шуток на русском языке.
Формат: JSON, UTF-8, массив объектов. Каждый объект содержит id (уникальный постоянный строковый идентификатор salary-joke-001 … salary-joke-100) и text (текст реплики).

ПРАВИЛА ПОДКЛЮЧЕНИЯ
1. При каждом успешном начислении зарплаты случайно выбрать одну реплику из массива, исключив идентификатор предыдущей показанной реплики. При равновероятном выборе все оставшиеся реплики имеют одинаковый шанс.
2. Показать text под основным уведомлением о начислении зарплаты. При повторном открытии того же уведомления сохранить выбранную реплику, не начислять зарплату повторно.
3. Шутка не влияет на сумму зарплаты, баланс, условия начисления или сюжетный прогресс.
4. Тайный пароль для архивной находки остаётся отдельным элементом уведомления. Не включать его в массив шуток и не связывать его показ с результатом случайного выбора.
5. Хранить ID последней показанной реплики вместе с состоянием игрока, чтобы исключать непосредственный повтор между входами.
6. При добавлении новых шуток использовать новые уникальные ID; существующие ID не менять и не переиспользовать.

ПРОВЕРКА
Массив содержит ровно 100 записей, уникальных текстов и идентификаторов. Тексты сохранены в утверждённой последовательности без редакторских изменений. После загрузки JSON прочитан из основной ветки и сопоставлен с загруженным содержимым.
Интеграция и проверка отображения в приложении ещё предстоят.
