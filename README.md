# Исторический архив

«Исторический архив» — игровая историческая викторина для VK Mini Apps: игрок отвечает на вопросы о реальных исторических личностях, раскрывает факты в коллекции и продвигается по сюжетным линиям современного архива.

## Игровые данные

Подготовлена версия датасета от **23 ноября 2026 года**:

- **390** исторических личностей;
- **10** тематических категорий;
- **2 681** активный исторический факт;
- **2 254** автоматически сформированных вопроса с четырьмя вариантами ответа.

Игрок открывает конкретный факт о личности за правильный ответ. Неправильный ответ не открывает факт. Спорные значения были удалены или заменены на конкретные подтверждаемые факты; дополнительной логики приблизительных дат нет.

### Структура файла Excel

| Лист | Содержимое |
| --- | --- |
| Персоны | Личности, идентификаторы и категории |
| Факты | Активные исторические сведения и ссылки на источники |
| Вопросы | Варианты ответа, правильный ответ и ссылка на открываемый факт |
| Широкий формат | Одна строка на историческую личность |
| Проверка | Контроль структуры и игрового наполнения |
| Инструкция | Описание формата для интеграции |

## Проверка и ограничения

Проведена историческая сверка реестра фактов и техническая проверка собранной базы: сохранены все 390 личностей, у каждой как минимум три активных факта, нет повторяющихся пар «личность — поле», каждый сформированный вопрос имеет четыре различных варианта и один назначенный верный ответ.

**Важно:** автоматическая структурная проверка вопросов не заменяет редакторскую вычитку всех формулировок и тестирование в самой игре. Часть свободных описаний сохранена как факты коллекции без автоматической генерации вопроса.

Финальный файл сформирован из проверенного реестра, поскольку первоначальная широкая таблица не была доступна при сборке. Для интеграции необходимо проверить соответствие структуры Excel существующему коду игры.
